# Wallpaper provenance

All bundled wallpapers are stored as WebP at quality 82. The conversion strips
C2PA metadata, so generation provenance is retained here instead.

The prompts are reproduced verbatim from the 2026-07-24 generation, with only the
product name updated at the rename to Talminal (2026-08).

`liquid-only` is a synthetic option rendered from translucent CSS gradients,
smoke, highlights, and the liquid displacement filter. It has no image asset.
